Getting started
  1. Pick a model type and model on the left.
  2. Tick the LoRAs you want to compare (or none).
  3. Write a prompt above — or describe an idea and press ✨ Write. Click tags in the Tag library to add them.
  4. Press Generate (or Ctrl+Enter). Every LoRA gets its own column with the same seed.
Optional: a Character keeps a look, outfit and LoRAs together; Reference images let you start from a photo.
